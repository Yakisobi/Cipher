how to install:

__________________________________________________________

Requirements: 
- Python 3 installed on your computer.
- Tkinter available (usually included with Python on Windows and macOS).

__________________________________________________________

1. Download the Project
Clone the repository using Git:

git clone https://github.com/Yakisobi/Cipher.git

cd Cipher

Alternatively, click Code → Download ZIP on GitHub and extract the downloaded folder.

__________________________________________________________

2. Launch Cipher

Open a terminal in the project folder and run the command for your operating system.

Windows:  py main.py

macOS / Linux:  python3 main.py

Alternatively, click Code → Download ZIP on GitHub and extract the downloaded folder.

__________________________________________________________

3. Run the Built-In Tests (Optional)

To check that the password generator's built-in tests pass, run:

Windows:
py main.py --selftest

macOS / Linux:
python3 main.py --selftest

The program will report the test results in your terminal.

__________________________________________________________

Troubleshooting:

- Python is not recognized: Install Python 3 and ensure it is available in your system's PATH.
- Tkinter is missing: On Ubuntu or Debian Linux, install it with sudo apt install python3-tk.
- The application does not open: Run the launch command in a terminal to view any error messages.

No additional packages are required to run Cipher.
